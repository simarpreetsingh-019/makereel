Jobs

Checks each channel every few minutes and uses almost no CPU while nobody is live. New videos are clipped as soon as they appear; a channel's older videos are left alone. Keep makereel running (or start it with makereel web --watch on a machine that stays on).

AI judge (optional)

An AI model reads the moments makereel shortlisted and scores them like an editor (hook, engagement, value, shareability), then writes better titles. Without it, picks come from loudness, chat and words only.
