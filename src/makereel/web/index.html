Creator memory

Per creator: names, places and in-jokes their captions should spell exactly right, and a few notes for the AI word-fixer. Stored on this computer.

Only needed if YouTube says "Sign in to confirm you're not a bot". makereel first tries other ways in by itself; if YouTube still refuses, it uses your sign-in, read on this computer and sent only to YouTube.

How to make a sign-in file (works even when your computer blocks browser access)
  1. In your browser, install a "Get cookies.txt LOCALLY" extension (Chrome Web Store or Firefox Add-ons).
  2. Open youtube.com, make sure you're signed in, click the extension, and export cookies.txt.
  3. Press Upload sign-in file here. makereel keeps only the YouTube and Google lines, on this computer.
